# Snake Game (Python + Pygame)

A simple and fun Snake Game built using Python’s **Pygame** library.

## How to Play
- Use arrow keys to move the snake.
- Eat the red food to grow.
- Don’t hit the walls or yourself!

## Setup
```bash
pip install pygame
python snake_game.py
```
